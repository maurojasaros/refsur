# RefSur

E-commerce de muebles y casas con pago Webpay (sandbox).

## Tecnologías
- Django
- SQLite
- Bootstrap
- Transbank SDK

## Ejecutar
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
